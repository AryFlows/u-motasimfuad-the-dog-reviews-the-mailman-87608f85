One funny one-line review a dog gives the mailman, written to `/output/entry.txt` by `main.py` (Python 3, stdlib only, no network).

## The line

> One star: he bribes me with a biscuit every morning, then looks betrayed when I bark for a second one. Buddy, you set the price.

The joke is the dog's side of the visit: a daily bribe that backfired, told in
the dog's own priorities (biscuits first, dignity second), with the turn at
the end — the mailman set the price, so the barking is just renegotiation.

## Run

```sh
python3 main.py
```

The program writes exactly one line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
